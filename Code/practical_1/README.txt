===== RUNNING THE PROGRAM ====

Conveniently, there is a Makefile to run the program, therefore we can easily run locks.java by doing the following:
1. Navigate to terminal in the same directory as locks.java
2. Type the following and enter, after which the program will run in terminal:
    make all
    make run
3. To clean up, type the following and enter
    make clean
